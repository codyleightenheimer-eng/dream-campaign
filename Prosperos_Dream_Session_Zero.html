Before Boarding — Table Setup Required

Session Zero

One sit-down before the campaign starts. Nobody builds a character alone, nobody discovers a house rule mid-crisis, and everybody knows what they signed up for.

1. Frame 2. Table 3. House Rules 4. Safety 5. Crew 6. Logistics

Step 1

Pick the Campaign Frame

Prospero's Dream can run a lot of different ways. Decide together which shape fits this table before anyone builds a character — it changes what a good character concept even looks like.

FrameWhat it plays like
Job to jobEpisodic. The crew takes contracts from Angus and others, station politics stay mostly in the background. Lowest commitment, easiest to run with a rotating table.
Pick a sideThe crew gets pulled into the Bratva / Stratemeyer / Teamsters power struggle early and has to actually choose allegiances. Higher stakes, more roleplay-forward.
Survive the DreamHorror-forward. The Choke, Caliban, and the station's darker corners take center stage sooner. Fewer factional politics, more dread.
Open tableNo fixed frame — the Warden follows player hooks and lets the campaign shape declare itself over the first few sessions.
Ask the table

"When you picture a great session of this campaign, what's actually happening on screen — a heist, a standoff, an investigation, a chase, a quiet dread-filled crawl through somewhere you shouldn't be?"

Step 2

Table Expectations

Settle these before the first dice hit the table. None of them are wrong answers — they just need to be shared answers.

Cadence

Weekly, biweekly, monthly — pick a rhythm the whole table can actually sustain. Irregular scheduling kills more campaigns than bad dice.

Session length

3–4 hours is the assumed default for the built session materials. Confirm it works for this table.

PvP

Mothership allows player-vs-player friction (see the PSG's own example of play). Decide as a table whether that's in bounds, and how far.

Character death and replacement

Confirm everyone's bringing a backup concept. Agree on how a new character gets introduced when the old one doesn't make it.

Recording / streaming

If this is being recorded or streamed for an online table, get explicit consent now, not after something personal comes up in play.

Step 3

House Rules

Mothership's default rules are already tuned, but this campaign runs long — built on returning to the same vendors, the same factions, the same relationships over dozens of sessions. A few house rules from the Warden's Operations Manual (pg.52.1) are locked in specifically to protect that long-term investment without softening the horror.

Ablative Wounds

Every character gains 1 extra Wound that, when lost, doesn't force a roll on the Wound table. Regains after 30 minutes of rest. Takes the worst edge off a single unlucky hit.

Impenetrable Wounds

Excess damage doesn't carry over once a Wound is triggered. Death still happens — it happens because things actually went wrong, not because of stacked bad rolls on top of an already-triggered Wound.

High Score Breaker

If a character beats the player's prior high score before dying, the next character gets 20 points to split between Stats and Saves. Losing a character here means losing real relationships and standing — this softens that loss without erasing the consequence.

Rapid Skill Learning

A Trained Skill takes 3 sessions to learn, Expert takes 5, Master takes 10 — much faster than the default pace. Keeps growth visible session-to-session over a genuinely long campaign.

Opt-In Stress

Players volunteer to gain Stress and make Panic Checks when they feel it's narratively appropriate, rather than every trigger being mandatory. Shifts some tension-pacing control to the table.

Player Facing Rolls

Players make all the rolls. In a violent encounter, a missed attack roll against an enemy can instead mean the player's character gets hit. Keeps the Warden's hands clean and puts the tension in the players' dice.

Write these into the Campaign Notebook as a standing House Rules page. Revisit and adjust as the table gets more comfortable — per the WOM's own advice, these aren't set in stone.

Step 4

Safety Tools

This is a horror game with body horror, corporate exploitation, violence, and psychological content built into the setting. Set up the tools now, while nothing's on the line yet.

Pick one and confirm everyone knows how to use it

Open door policy. Anyone can step away from the table at any time, no explanation needed, no questions asked on return.

Lines and veils. Lines: content that doesn't happen at this table, full stop. Veils: content that can happen but fades to black rather than playing out on-screen. Collect both privately or as a group, Warden's call.

A live signal. A word, a hand gesture, or (for online tables) a chat command that means "pause and check in" without breaking character for everyone else.

Whatever you pick, say out loud that it's a standing policy for the whole campaign — not just tonight. Revisit it if the campaign frame shifts toward something heavier later.

Step 5

Build the Crew

Characters get built together, at the table, so the crew starts connected instead of four strangers who happen to share a ship.

Roll stats, saves, pick a class

Standard PSG character creation. See the player pitch document for the four core options if anyone needs a refresher.

Establish why this crew is a crew

One shared reason they're together already beats four separate backstories that never intersect. Doesn't need to be deep — a shared debt, a shared ship, a shared employer all work.

One connection per pair

Go around the table — each player states one concrete thing their character knows or feels about another PC. Not required to be positive.

Decide why the Dream, specifically

Everyone should have a one-line reason their character is arriving at Prospero's Dream now — running from something, chasing something, or just following the work. This feeds directly into the cold open of session 1.

Step 6

Final Logistics

  • Confirm everyone has (or knows where to find) the core rules reference — Panic Table, Wounds Table, basic Stat Check procedure.
  • Confirm the note-taking plan — who's tracking Debt, NPC names, and open threads between sessions.
  • Share the NPC database and player pitch document links with the table for reference between sessions.
  • Set the date for session 1.
  • Ask if anyone wants anything added to, or removed from, the campaign before it starts. Last chance before the ship leaves dock.
